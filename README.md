# 🍅 TomaTron — Tomato Detection & Classification

A computer vision system that detects, counts, and classifies tomatoes by ripeness stage in real-world images and video using **DETR (Detection Transformer)** with a **ResNet-50** backbone, built on PyTorch and HuggingFace Transformers.

> **v2.0** — Upgraded from Mask R-CNN (TensorFlow) to DETR (PyTorch + HuggingFace). Same dataset, same classes, faster setup, no custom C++ dependencies.

---

## 🎯 Features

- **Detection** — Draws bounding boxes around individual tomatoes in images and video
- **Classification** — Classifies each detected tomato into one of three ripeness stages:
  - 🟢 Unripe
  - 🟠 Semi-ripe
  - 🔴 Ripe
- **Counting** — Counts total tomatoes per image/frame with per-class breakdown
- **Image inference** — Run detection on a single image with annotated output saved
- **Video inference** — Process video files or live webcam feed with real-time FPS display
- **Real-world ready** — Trained on images of tomatoes attached to plants in natural environments

## 🔄 Dataset Preparation (VIA → COCO)

The training script expects COCO format JSON. If you have raw VIA annotation exports, convert them first:

```bash
python via_to_coco.py
```

This reads `dataset/train/train_json.json` and `dataset/val/val_json.json` and writes `train_coco.json` and `val_coco.json` alongside them. Run this once before training.

**Note:** Open `via_to_coco.py` and check this line matches the attribute name you used in VIA:
```python
CLASS_ATTRIBUTE = "names"
```

## 🏋️ Training

```bash
python tomato_training.py
```

**What it does:**
- Loads COCO JSON annotations from `dataset/train/` and `dataset/val/`
- Auto-discovers class names from the JSON categories
- Fine-tunes `facebook/detr-resnet-50` for your classes
- Saves the best checkpoint (lowest val loss) to `tomato_detection_model/`

**Key settings** at the top of `tomato_training.py`:

```python
BATCH_SIZE    = 2        # increase to 4 if you have more than 8 GB VRAM
EPOCHS        = 10
LEARNING_RATE = 1e-4
CONFIDENCE    = 0.5      # detection threshold at inference time
IMAGE_SIZE    = {"shortest_edge": 480, "longest_edge": 800}  # reduce if OOM
```

Monitor training — loss should decrease each epoch:
```
Epoch 1/10  → Train Loss: 2.37 | Val Loss: 1.84
Epoch 10/10 → Train Loss: 1.25 | Val Loss: 1.22
```

## 🔍 Inference

### Single Image

```bash
python tomato_inference.py
```

Update the image path at the top of the script:
```python
TEST_IMAGE_PATH = script_dir / "Classification_Images" / "test_tomato.png"
```

**Output example:**
```
=============================================
  TOTAL TOMATOES DETECTED : 8
---------------------------------------------
  ripe          3  ███
  semiripe       2  ██
  unripe         3  ███
=============================================
```

An annotated image is saved to `Classification_Images/result.jpg` and displayed in a window.

### Video / Webcam

```bash
python tomato_inference_video.py
```

Update the video path at the top of the script:
```python
VIDEO_PATH = script_dir / "Classification_Images" / "test_video.mp4"
```

- If the video file exists → processes it frame by frame
- If the video file is **not found** → automatically opens your webcam
- Press **Q** to stop at any time
- Annotated video saved to `Classification_Images/result_video.mp4`
- Live FPS counter and per-class counts shown in the top-right corner

**Tip:** If detections are too few or too many, adjust the confidence threshold:
```python
CONFIDENCE = 0.5   # lower = more detections, higher = fewer but more confident
```
